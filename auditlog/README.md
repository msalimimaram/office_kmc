# اپ auditlog — رویدادهای حسابرسی

## مسئولیت
مدل `AuditEvent` برای ثبت عامل، نوع عملیات، نوع/شناسه شیء، شرح، IP و زمان ایجاد طراحی شده است.

## کاربرد
برای عملیات حساس، رویداد باید به شکلی ثبت شود که عامل و موضوع عملیات قابل پیگیری باشند؛ در عین حال شرح رویداد نباید حاوی رمز، شماره شبا کامل، کد ملی کامل یا محتوای سند باشد.

## محدودیت مهم
وجود مدل رویداد به‌تنهایی به معنی ثبت خودکار همه تغییرات نیست. باید محل‌های فراخوانی، پوشش عملیات و شکست‌های ثبت رویداد در هر اپ بررسی شوند.

## تست‌های مهم
ثبت actor و زمان، عملیات موفق/ناموفق، پاک‌سازی داده حساس، تغییر رکوردهای مهم و محدودیت دسترسی به گزارش حسابرسی.

## موارد باز
سیاست نگهداری، دسترسی فقط خواندنی برای نقش‌های مجاز، یکپارچگی رویدادها و پوشش کامل عملیات حساس نیازمند تعریف و آزمون است.
