# اپ core — اجزای مشترک

## مسئولیت
این اپ منطق مشترک مورد استفاده اپ‌های دامنه را نگه می‌دارد؛ از جمله helperهای نقش/محدوده داده در `permissions.py`، اعتبارسنجی فایل در `uploads.py` و تست‌های مرتبط.

## مجوزها
`role_required` برای محدودسازی بر اساس نقش است. `scoped_claims_for` و `scoped_requests_for` queryهای محدودشده برای چند نقش فراهم می‌کنند. فراخوانی صحیح این helperها در همه viewها الزامی است و استفاده از آن‌ها جایگزین تست جامع هر endpoint نیست.

## اعتبارسنجی فایل
`uploads.py` محدودیت‌های اندازه/پسوند و بررسی ساختار برخی فرمت‌ها را اعمال می‌کند. این کنترل‌ها تشخیص بدافزار نیستند و باید با ذخیره‌سازی خصوصی و اسکن بدافزار تکمیل شوند.

## تست‌های مهم
هر نقش و حالت بدون رابطه، کاربر بدون company/insurer، تلاش دسترسی بین tenantها، پسوند/امضای ناسازگار، فایل خراب، اندازه بیش از حد و آرشیو بزرگ.

## اصول نگهداری
اجزای مشترک را مستقل از UI بنویسید، ورودی‌ها را صریح کنید و برای هر تغییر مجوز یا validator تست مثبت و منفی اضافه کنید.
