# چک‌لیست انتشار

این چک‌لیست باید برای هر انتشار کپی و تکمیل شود. موارد تأییدنشده را «انجام‌شده» علامت نزنید.

## کد و ساخت
- [ ] commit نهایی مشخص و بازبینی شده است.
- [ ] وابستگی‌ها بازبینی شده‌اند.
- [ ] migrationهای لازم commit شده‌اند.
- [ ] نصب از checkout تمیز انجام شده است.
- [ ] `python manage.py check --deploy` بررسی شده است.
- [ ] `python manage.py makemigrations --check --dry-run` موفق است.
- [ ] `python manage.py migrate --check` موفق است.
- [ ] تست‌ها در CI و محیط staging موفق‌اند.

## امنیت و داده
- [ ] هیچ secret یا داده واقعی در Git/log/test fixture وجود ندارد.
- [ ] جداسازی شرکت‌ها و بیمه‌گرها با تست منفی تأیید شده است.
- [ ] مجوز دانلود تمام فایل‌ها تأیید شده است.
- [ ] MFA، محدودسازی ورود و بازیابی حساب طبق معیار مصوب آزموده شده‌اند.
- [ ] فایل‌های بارگذاری‌شده اسکن بدافزار می‌شوند یا بهره‌برداری تا فعال شدن آن متوقف است.
- [ ] دسترسی Admin و حساب‌های privileged بازبینی شده است.

## عملیات
- [ ] HTTPS و hostهای مجاز تأیید شده‌اند.
- [ ] PostgreSQL و مجوزهای دسترسی حداقلی تنظیم شده‌اند.
- [ ] backup رمزگذاری‌شده تهیه و بازیابی آن آزمایش شده است.
- [ ] پایش خطا و راه تماس رخداد مشخص است.
- [ ] روش rollback کد و schema ثبت شده است.

## پذیرش کاربر
- [ ] آزمون موبایل در عرض‌های 360، 390 و 430 پیکسل انجام شده است.
- [ ] مسیرهای اصلی با هر نقش آزموده شده‌اند.
- [ ] کاربر کسب‌وکار گردش‌کارها و اصطلاحات را تأیید کرده است.
- [ ] موارد باز، مالک و موعد پیگیری دارند.
