# راهنمای آزمون و CI

## اهداف

آزمون‌ها باید رفتار دامنه، اعتبارسنجی ورودی، دسترسی نقش‌ها، جداسازی داده‌ها، امنیت فایل و مسیرهای حساس را پوشش دهند. موفقیت تست‌های فعلی تضمین‌کننده نبود نقص نیست.

## اجرای محلی

```powershell
python manage.py check
python manage.py test
python manage.py test accounts organizations claims requests_portal imports core
```

برای بررسی migrationها:

```powershell
python manage.py makemigrations --check --dry-run
python manage.py migrate --check
```

## CI فعلی

Workflow در `.github/workflows/django.yml` برای Python 3.11 و 3.12 اجرا می‌شود و بررسی سیستمی و تست Django را انجام می‌دهد. اگر workflow برای دیتابیس تست migration تولید کند، این فقط برای همان اجرای CI است و migrationهای تولیدی را به مخزن اضافه نمی‌کند.

## استاندارد تست برای تغییر جدید

- **Unit:** متدهای مدل، validatorها و helperها.
- **View/integration:** status code، redirect، پیام، ذخیره‌سازی و خطاهای فرم.
- **Authorization:** نقش مجاز/غیرمجاز، شرکت دیگر، بیمه‌گر دیگر، شناسه دست‌کاری‌شده و دسترسی به فایل.
- **Workflow:** وضعیت‌های مجاز و غیرمجاز، ارجاع، تکمیل و رد.
- **Import:** فایل ناقص/خراب، ستون گمشده، ردیف تکراری، تاریخ/مبلغ نامعتبر، آرشیو حجیم و عدم ثبت جزئی داده نامعتبر.
- **Regression:** باگ اصلاح‌شده باید تستی داشته باشد که پیش از اصلاح شکست بخورد.
- **UI acceptance:** عرض‌های موبایل، فرم‌های طولانی، جدول‌ها، pagination، focus و لمس.

## حداقل ماتریس مجوز

| نقش | دامنه‌ای که باید آزموده شود |
|---|---|
| مدیر سامانه | مدیریت لازم؛ دسترسی privileged بازبینی شود |
| رئیس اداره | دید سراسری مورد تأیید کسب‌وکار |
| کارشناس | پرونده‌های تخصصی/ارجاع‌شده |
| نماینده شرکت | فقط شرکت متصل به حساب |
| بیمه‌شده | پرونده‌های خود و وابستگان مجاز |
| بیمه‌گر | پرونده‌های بیمه‌گر متصل |
| مالی/حقوقی/حسابرس | فقط اطلاعات موردنیاز نقش |

این جدول هدف آزمون است، نه ادعای اینکه همه موارد از قبل پوشش داده شده‌اند.

## معیار خروج برای نسخه آزمایشی

- تست‌ها و system check بدون خطای ناشناخته.
- migrationها در Git موجود و روی دیتابیس خالی آزموده شده‌اند.
- تست مجوز بین tenantها و دسترسی مستقیم به فایل‌ها پاس شده است.
- داده تست ساختگی است.
- باگ‌ها و موارد خارج از پوشش در گزارش انتشار ثبت شده‌اند.
