# اپ imports — ورود گروهی Excel

## مسئولیت
ثبت عملیات ورود گروهی با شماره batch، نوع داده، فایل، بارگذار، وضعیت، شمار ردیف‌ها، گزارش نتیجه و داده پیش‌نمایش.

## قالب فعلی خسارت
ستون‌های الزامی: `claim_number`، `national_id`، `service_type`. ستون‌های اختیاری: `service_date`، `registered_date`، `requested_amount`، `assessed_amount`، `payable_amount`، `paid_amount`، `payment_date`. تاریخ به شکل `YYYY-MM-DD` انتظار می‌رود.

## اعتبارسنجی
فرم ورودی، فایل‌های Excel مجاز را با سقف اندازه و بررسی ساختار آرشیو/وجود workbook بررسی می‌کند. این بررسی‌ها جایگزین اسکن بدافزار نیستند. ورودی نامعتبر باید خطاهای قابل فهم تولید کند و نباید باعث ثبت ناقص یا تکراری داده شود.

## گردش کار
وضعیت‌های مدل شامل بارگذاری‌شده، اعتبارسنجی‌شده، پردازش‌شده و ناموفق است. پیش از تغییر رفتار پردازش، مشخص کنید کدام مرحله فقط preview است و کدام مرحله واقعاً داده اصلی را commit می‌کند.

## تست‌های مهم
فایل خراب، پسوند غیرمجاز، فایل بیش از حد بزرگ، ZIP bomb، ستون گمشده، شناسه تکراری، تاریخ و مبلغ نامعتبر، شناسه ملی مبهم بین چند شرکت، خطای میان‌راه و عدم ایجاد داده تکراری.

## موارد باز
برای حجم‌های بالا صف پس‌زمینه، محدودیت مصرف منابع، قابلیت retry/audit batch و سیاست نگهداری فایل‌های ورودی باید طراحی شوند.
